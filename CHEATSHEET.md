# Шпаргалка

Команды, которые набирает автор. Не справочник по Claude Code —
в неё попадает строка, которая уже понадобилась хотя бы раз.
Строка без даты проверки в этом окружении сюда не пишется.

## Контекст сессии

    /context     что сейчас в окне и чем занято
    /compact     сжать диалог, освободить окно

`/context` читать по строке **Messages**: она растёт от того, что
прочитано в этом окне. Сабагент её почти не двигает.

## Репозиторий

    cd ~/storage/shared/python-learning
    git pull --ff-only origin main
    git push -u origin main

Между `pull` и `push` не тянуть: на репозиторий пишут две сессии,
одновременно писать должна одна.

## CI в llm-prompts

    gh run list --repo Lyverance/llm-prompts --limit 5 \
      --json conclusion,displayTitle -q '.[] | .conclusion + "  " + .displayTitle'

Без `--json` и `-q` колонки схлопываются на ширине телефона.

## Локальная сессия

    claude remote-control     ввод из приложения, выполнение здесь
    /list-agents              какие сессии видны, кому можно писать

Запускать из каталога проекта, под `termux-wake-lock`. Закроешь
Termux — сессия отвалится.

Аккаунтные скиллы в локальную сессию, один раз:

    CLAUDE_CODE_SYNC_SKILLS=1 claude -p "перечисли доступные скиллы"

## Облачные сессии из терминала

    claude --cloud "текст задачи"          новая сессия в облаке
    claude -p "уточнение" --cloud <id>     дописать в существующую
    claude --teleport <id>                 втянуть облачную в терминал

Облачная сессия не отчитывается в диалог. Обратный путь — git
или `--teleport`.

## Агенты

    /agents      список, создание, правка

Агент читается при старте сессии. Созданный на ходу по имени
не вызывается — перезапустить сессию.
